# 앵커늘봄 강사서류 작성

호서대학교 앵커늘봄총괄센터 · 강사 계약 서류(주강사·보조강사) 작성 화면

- 강사 정보를 한 번 입력하면 0~12번 한글 서류를 학교별로 채워 ZIP으로 저장합니다.
- 강사가 낸 서류(ZIP·HWP·HWPX·PDF·JPG)를 끌어다 놓으면 빈칸을 미리 채웁니다.
- 확정 운영 목록(엑셀)을 넣으면 학교·기관별 운영 현황을 정리하고 강사 기준정보(구분·연락처·학교·프로그램)를 만듭니다.
- 학교·기관 담당자에게 보낼 메일(제목·본문)과 그 학교 강사들의 서류 ZIP을 만듭니다.
- 운영 목록을 화면에서 직접 고칠 수 있습니다(학교 이름·담당자, 수업 고치기·추가·지우기).
- 「준비·발송 현황」에서 강사×학교마다 서류 준비 여부와 발송 여부를 봅니다.
- 파일·폴더·ZIP 이름을 고칠 수 있습니다.
- 「⑤ 증명서」에서 운영현황의 수업을 골라 경력증명서·출강증명서(한글)를 만듭니다.
- 구글 시트 연동(앱스 스크립트)을 설정하면 운영현황 구글 시트를 링크로 바로 읽고, 증명서 발급 내역을 공유드라이브 날인대장에 누적 기록합니다. 연동 주소와 접근 코드는 각 브라우저에만 저장합니다.
- 운영현황은 「적용 학기」로 학기(파일)별로 나눠 진행합니다(처음에는 가장 나중 학기 하나). 증명서 발급만 모든 학기를 합쳐서 봅니다.
- 학교밖 기관(초등학교 이외)은 학교별 서류 중 0번만 만들고, 학교 폴더 없이 강사 폴더 바로 아래에 둡니다(3·7·8·9·10번 제외).
- 강사 자료 공유: 「운영현황 → 구글 시트 연동」에서 켜면 강사 입력값과 스캔본을 공유드라이브 폴더로 다른 직원과 맞춥니다. 바뀐 강사만 받아 오고 스캔본은 그 강사를 열 때만 받습니다.
- 공유드라이브에서 불러오기: 「제출서류 불러오기 → 공유드라이브에서」로 공유드라이브 강사서류 폴더의 ZIP·강사별 폴더를 골라 바로 불러옵니다(큰 ZIP은 조각으로 받음).
- 모든 처리는 **사용자 브라우저 안에서만** 합니다. 입력한 개인정보는 서버로 보내지 않고, 그 PC의 브라우저(IndexedDB)에만 저장됩니다.

## 주의
- 강사 개인정보가 든 파일(운영 목록 엑셀, 강사가 낸 서류, 생성한 ZIP)은 이 저장소에 올리지 마세요. GitHub Pages 사이트는 누구나 볼 수 있습니다.
- 고칠 때마다 index.html 의 `APP_VERSION` 날짜를 바꿔 주세요.
- 강사 목록: 운영현황에는 있는데 등록하지 않은 강사를 「미등록」으로 함께 표시(등록·서류 제출 요청 가능). 서류 제출·보완 요청 화면에서 미등록 강사에게 서류 전체 제출 요청 문자를 만들 수 있음.
- 발송·요청 기록 공유(강사 자료 공유를 켠 브라우저끼리), 발송 기록 학기별 구분, 재요청 횟수·경과일, 채용신체검사서 기한 알림, 학기 반영(운영현황에 맞추기), 만든 서류를 공유 폴더 「생성서류」에 저장.
- 강사 직접 제출(apply.html): 직원이 만든 개인 링크 + 본인 확인(생년월일 또는 연락처 뒤 4자리)으로 강사가 본인 자료만 입력·업로드. 바로 서명 가능.

## 운영 관리(접수·배치) 통합 — `manage/`
「초등방과후 프로그램 운영 관리」(학교·기관 접수, 강사 모집·배치, 운영 목록, 통계)를 이 저장소로 옮긴 화면이다.
- 화면: `manage/index.html` 한 파일. 주소 규칙은 예전 웹앱과 같다 — 운영 `manage/?a=운영자키`, 강사 `manage/`, 보조강사 `manage/?r=asst`, 기관 담당자 `manage/?join=1`, 기관 전용 `manage/?s=토큰`, 타대학 `?u=`, 통계 `?st=`, 사업 `&b=vac`.
- 데이터·서버: 운영 관리 앱스 스크립트(구글 시트)를 그대로 쓴다. 화면은 `google.script.run` 대신 웹앱 주소로 `{fn, args}`를 보낸다(`Code.gs`의 `doPost`, 허용 목록 `RPC_FNS_`). 웹앱 주소는 `manage/config.js`의 `OPS_API`.
- 원본: `manage/_src/` — `src2.html`(화면 원본) → `to_gas.py` → `Lib.html`·`Styles.html`, `App.html`(껍데기) → `build_pages.py <gas 폴더>` → `manage/index.html`. `Code.gs`는 저장소에 올리지 않는다.
- 강사서류 화면 왼쪽 메뉴 「⑥ 운영 관리」에서 연다. 「접수·배치 관리」는 운영자 링크를 처음 한 번 묻고 이 브라우저에만 기억한다(Shift+클릭으로 다시 입력).
- 예전 웹앱 주소(`script.google.com/…/exec`)도 그대로 동작한다. 학교·강사에게 나가는 링크를 새 주소로 바꾸려면 운영 화면 「1 기준정보 → 웹앱 주소」에 `https://hoseoican.github.io/hoseo_docs/manage/`를 넣는다.
- 운영 통계 「자료 올리기 → 강사서류 운영현황 시트 불러오기」: 강사서류 화면 「운영현황」에 등록한 구글 시트 목록(강사서류 연동 `ping`의 `ops`)을 받아 운영 관리 서버(`adminSheetRead`)로 읽는다. 같은 브라우저의 강사서류 연동 설정(IndexedDB `anchor-lecturer-docs` › `kv` › `gas`)을 쓴다. 시트 등록·삭제는 강사서류 화면 한 곳에서만 한다.
