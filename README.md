# 강사서류 작성 프로그램 — 옮겼습니다

이 프로그램은 **초등방과후 프로그램 운영 관리** 저장소 [hoseoican/hoseo_ops](https://github.com/hoseoican/hoseo_ops)의 `docs/` 폴더로 옮겼습니다.

- 새 주소: https://hoseoican.github.io/hoseo_ops/docs/ (운영 관리 화면 「9 강사서류」에서도 열림)
- 강사 제출 화면: https://hoseoican.github.io/hoseo_ops/docs/apply.html

이 저장소에는 예전 주소로 들어온 사람을 새 주소로 넘기는 안내 파일만 남겨 두었습니다.
- `index.html` → 새 강사서류 화면(운영자 링크를 기억한 브라우저는 운영 관리 「9 강사서류」)
- `apply.html` → 새 강사 제출 화면(링크의 `?t=` 값 그대로)
- `hoseo-mail-bridge.user.js` → 이미 설치한 메일 보내기 스크립트가 새 주소로 자동 업데이트되도록 남김

예전 코드와 변경 기록은 이 저장소의 git 기록에 그대로 있습니다.
